# Decentralized Deep Learning

by Tom Hagander and Eric Ihre-Thomason

This repository contains the code for our master's thesis at Lund University, written with the RISE Deep Learning Group (Research Institutes of Sweden, Gothenburg) in 2024. The thesis compares communication strategies and similarity metrics for decentralized deep learning, where clients collaborate on personalized models without sharing their data.

**Master's thesis**
With a Little Help from My Friends – A Comparative Study of Decentralized Deep Learning Strategies
[Lund University Student Papers](https://lup.lub.lu.se/student-papers/search/publication/9159064)

**Paper (TMLR, January 2025)**
On the effects of similarity metrics in decentralized deep learning under distributional shift
Edvin Listo Zec, Tom Hagander, Eric Ihre-Thomason, Sarunas Girdzijauskas
[OpenReview](https://openreview.net/pdf?id=WppTEs4Kkn)

The code is written in Python and PyTorch.
